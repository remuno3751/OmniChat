# 音声通話(Aria)

OmniChat から、**Aria**(別プロジェクトの AI-VTuber の音声通話サーバー)と、声で会話できます。通話の内容は、OmniChat の会話として残ります。

> **状態**: v1.1.0 の新機能です。擬似のサーバーでの動作確認までで、本物の Aria との接続や、実機のマイクでの通話は、まだ確認していません(下の「確認していないこと」)。

## しくみ

```
アプリ(Web / デスクトップ / Android)── OmniChat サーバー ── Aria(音声の認識・合成、返事づくり)
```

- アプリは、OmniChat サーバーだけにつなぎます。Aria の URL を、アプリに入力する必要はありません。
- サーバーが、Aria との間を中継し、話した内容と Aria の返事を、会話のメッセージとして保存します。
- Aria は、OmniChat には入っていません。別に用意します(Windows 専用)。サーバーアプリが、そのフォルダを指定して起動するか、すでに動いている Aria を URL で指します。

## 使い方(管理者)

1. **Server アプリ → 「音声通話」** を開きます。
2. モードを選びます。
   - **このPCで Aria を動かす**(Windows のみ): Aria のフォルダ(`AI_Assistant_Aria_v6`)を指定します。Python 3.11 と、Aria の依存が入っている必要があります(OmniChat は、インストールはしません。足りないものは、画面に案内が出ます)。声エンジン(AivisSpeech Engine)の URL も、専用の欄に入れます。「トークンを発行」で、Aria との接続に使うトークンを作ります。
   - **外部の Aria**: すでに動いている Aria の URL と、トークン(通話用の `chat` と、管理用の `admin`)を入れます。
3. 通話で使う LLM(fast = 通話の返事、deep = 背景思考)を、画面で選びます。ユーザー全員に共通です。
4. 必要なら、1日あたりの通話時間の上限(全員共通、ユーザーごとの上書きも可)を決めます。

## 使い方(ユーザー)

- チャット画面の上にある**電話のボタン**で、その会話の中で通話を始めます。話したことと、返事が、そのチャットに残ります。通話中は、メッセージ欄に打った文字も、通話に送られます。
- **記録しない通話**: 通話を始める前に、「この通話を、チャットの履歴に残さない」を選びます(Aria の記憶にも残りません)。
- **設定 → 音声通話**: 話し方(声のモード、速さ、間、割り込みの感度)、声の選択、押している間だけ話す(プッシュトゥトーク)、**声モデルのアップロード**、診断です。
  - 標準モード(AivisSpeech)の声: `.aivmx` をアップロードします。
  - Fast モード(piper-plus)の声: piper-plus 形式の `.onnx` と、設定の `config.json` をアップロードします。素の ONNX(ほかの形式)は、使えません。
  - 「つくよみちゃん」の声を使うときは、コーパスの利用規約(クレジット表記、用途の制限)に従ってください。
- 読み上げ速度の既定は、標準モードで 1.3、Fast で 1.0 です。
- つながらないとき: 設定の「診断」で、原因の切り分け(Aria に届くか、音声認識、声の方式、LLM の設定、マイクの許可など)ができます。

## 対応している端末

- Web 版と、デスクトップ版(Windows / Mac): 対応。マイクの許可が要ります。許可しないと、文字だけで通話を続けます。
- Android(ネイティブ): 実装しました(`react-native-audio-api`)。APK のビルドは通りましたが、実機の確認は、まだです。
- Aria を OmniChat のサーバーアプリから起動できるのは、Windows のみです。

## 確認していないこと

- 本物の Aria との接続、実機のマイクでの通話(エコー除去と、割り込みの判定を含む)。
- Opus の実際の音(WebCodecs が使える環境のみ。使えないときは PCM16 に戻ります)。
- Fast の声(piper)のアップロード(実在する piper-plus 形式のモデルで)。
- Server アプリが、本物の Aria を起動して管理する流れ。
- 通話中に、1日の上限を超えたときの切断。
- Android の実機、Mac の画面。
