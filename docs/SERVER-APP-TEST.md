# OmniChat Server アプリ: Windows 手動テスト(バックグラウンド / トレイ)

自動テスト(`cd server-app/src-tauri && cargo test --lib`)では、起動判定・設定の読み書き・トレイ文言までを確認しています。以下は実機の Windows でしか確かめられない項目です。インストール版(`%LOCALAPPDATA%\OmniChat Server`)を使い、確認前にタスクマネージャーで古い OmniChat Server が残っていないことを確かめてください。

## 1. ウィンドウを閉じてもサーバーが動く
1. アプリを起動し、サーバーが「稼働中」になるのを待つ。
2. ウィンドウの × を押す。
3. 確認: ウィンドウが消え、タスクトレイ(隠れたインジケーター内)にアイコンが残る。ブラウザーで `http://localhost:8787/` が開く。タスクマネージャーに `omnichat-server-app` と `node.exe` がある。

## 2. トレイ
1. トレイのアイコンにカーソルを置く → 「OmniChat Server — running on port 8787」。
2. 左クリック → ウィンドウが表示される(最小化していても復元され、前面に出る)。
3. 右クリック → 「ウィンドウを開く」「Running — http://<IP>:8787」(押せない)「サーバーを再起動」「Web 画面を開く」「終了(サーバーも停止)」。
4. 「サーバーを再起動」 → 数秒後に再び `http://localhost:8787/` が開く。
5. 「終了(サーバーも停止)」 → トレイのアイコンが消え、`http://localhost:8787/` に繋がらない(ポートが閉じる)。`node.exe` も消える。

## 3. アプリが強制終了されたとき(孤児の防止)
1. アプリを起動し、サーバーが動いていることを確認する。
2. タスクマネージャーで `OmniChat Server` を「タスクの終了」。
3. 確認: 数秒以内に `node.exe`(サーバー)も消え、`http://localhost:8787/` に繋がらない。
4. 次に起動しても、「ポートが使用中」にならない。

## 4. 自動起動(再起動後)
前提: 設定で自動起動オン、「PC の起動時(自動起動)は画面を出さず…」オン(既定)。
1. PC を再起動し、ログインする。
2. 確認: ウィンドウは出ない。約 30 秒後(設定した待機時間 + ネットワーク待ち)に `http://localhost:8787/` が開く。トレイにアイコンがある。
3. タスクスケジューラの「OmniChat Server Autostart」の操作が `--minimized --autostart` であることを確認(任意)。
4. 設定でオプションをオフにして再ログイン → 自動起動でもウィンドウが出る。

## 5. 初回起動
1. `%APPDATA%\dev.omnichat.server\setup-done` を退避(名前を変更)してからアプリを起動(自動起動のタスク経由でも、手動でも)。
2. 確認: どちらの場合もウィザードのウィンドウが出る。終えると `setup-done` ができる。

## 6. 手動起動と 2 回目の起動
1. 既定の設定でスタートメニューから起動 → ウィンドウが出る。
2. 「常に画面を出さない」をオンにして終了し、スタートメニューから起動 → ウィンドウは出ず、トレイのみ。
3. 同じ状態でショートカットに `--background` を付けて起動(オフでも)→ トレイのみ。
4. アプリが動いている(ウィンドウが隠れている / 最小化されている)状態でスタートメニューからもう一度起動 → 新しいプロセスは増えず、既存のウィンドウが前面に出る。

## 7. 黒い窓が出ない
上記の操作中(起動、自動起動、再起動、終了、設定の自動起動オン/オフ、ネットワーク表示)に、一瞬でも黒いコンソールウィンドウが出ないこと。
