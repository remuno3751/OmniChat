# テーマ実装メモ

クライアント(`app/`)のテーマ機構と、2 つの新テーマの実装メモです。画面に出す名前と内部 id は、どちらも **フロンティア / Frontier**(`frontier`)と **アストラル / Astral**(`astral`)です。色・形・動きはすべてこのアプリのオリジナルで、特定のゲームの名称・画像・文言は使いません。

## 構成

| 場所 | 役割 |
|---|---|
| `app/src/themes/types.ts` | `ThemeDef`(パレット、形、フォント、影、動き、装飾、バリアント) |
| `app/src/themes/{simple,frontier,astral}.ts` | 3 テーマの定義。Simple は従来の値そのまま |
| `app/src/theme.ts` | `useTheme()`(従来どおりフラットな色 + `hl`)、`useThemeDef()`(形・装飾・動きのトークン、`r(n)` で角丸をテーマの段階に丸める) |
| `app/src/fonts.ts` | テーマごとのフォントを使うときだけ読み込む(Simple は何も読まない) |
| `app/src/ui/textPatch.ts` | `fontFamily` 未指定の `Text` に、テーマの本文フォントを当てる(太字は太字の書体へ) |
| `app/src/ui/skin.tsx` | 画面から使うテーマ部品: 書体の役割(`useFaces`)、反転ラベル `Tag`、通知 `NotifyBadge`(橙の点 / 赤い「!」)、`NewTag`、見出し `SectionTitle`・区切り `Rule`、等高線 `Contour`、バーコード、四隅の印、段階表示 `LoadBar` / `NodeTrack`、吹き出し `Speech`、紋章 `Emblem`、入場モーション `Enter` / `useOnce`、押下 `pressStyle` |
| `app/src/ui/decor.tsx` | 背景(斜線 + 格子 / 星空 + 軌道)、角括弧、点線の内枠、四つ角の星、影。すべて静止・独自描画 |
| `app/scripts/check-contrast.mjs` | 全テーマ×モードの主要な色の組が AA を満たすか検査 |

デバイス設定: `themeId`(simple / frontier / astral)、`theme`(モード: system / light / dark。sepia / contrast は Simple のみ)、`decorations`(true / false / null=自動。自動は小さいスマホでオフ)。

## ルール

- 文字色としてのアクセントは `accentInk`、塗りは `accent`。ライトの黄色は塗りと線だけで、文字にしない。
- 角丸の直書きは `th.r(n)`(Simple は `n` のまま)。円形は直書きのまま。
- 動きは一度きり(開いたとき・出たとき)で、常時アニメーションはない。OS の「視差効果を減らす」と「装飾とエフェクト」のオフで 0 になる。
- Simple に影響する分岐は作らない(新しい部品は Simple では従来の描画か、何も描かない)。
- 装飾(背景、括弧、点線)は「装飾とエフェクト」で一括して切れる。ぼかし(backdrop blur)は使っていない。

## フォント(すべて OFL / Apache-2.0。`THIRD_PARTY_NOTICES.txt` に追記)

- フロンティア: Space Grotesk(本文・ラベル)、Syncopate(見出し)。日本語は OS のフォントにフォールバック。
- アストラル: Zen Maru Gothic(本文。日本語)、Outfit(数字・ラベル)、Marcellus(見出し)。Zen Maru Gothic は 1 書体が約 3.8MB なので、このテーマを選んだときだけ読み込む。
- Noto Sans JP は 1 ウェイトが約 5.7MB のため採用しなかった。

## 画面ごとの対応

| 部分 | フロンティア | アストラル |
|---|---|---|
| サイドバー | 上に銘板(四角の印 + OMNICHAT + バーコード)、Chat / Code は反転ラベルのタブ、選択中は左の太線(暗: 黄 / 明: 黒) | 手帳のタブ(選択中のタブが一覧と繋がる、上に琥珀の印)、選択中は左の琥珀の帯 |
| 通知 | Code セッションが承認待ちのとき Code タブに橙の点 | 同じ場所に赤い丸の「!」 |
| メッセージ | 角のないパネル + 左の縦線 + 四隅の小さな印、左から 8px 滑り込む | 角丸カード、ユーザーは金の細枠、返答の角に金の星、下から浮き上がる。ライトは点線の内枠 |
| 段階表示 | `[ 斜線のトラック ] 02/03` + 状態名 | 線で結んだノード(済 = 金のチェック、現在 = 金の輪、未 = 灰) |
| ポップアップ | 角括弧つきのプレート、上端に黄色の線が一度だけ伸びる、`//` 見出し、バーコード | 暗い枠 + 題名のタブ + 紙の本体(点線の内枠)、少し拡大しながら現れる |
| 入力欄・送信 | 角括弧、送信は暗い円 + 細いリング(入力ありでアクセント) | ピル、送信は白(ライトは暗茶)のピル |
| ヒント | 反転「TIPS:」+ 等高線 + 四隅の印 | 紋章が白い吹き出しで話す |
| 設定 | 番号付きの一覧、見出しは `//` + 罫線 | 選択中はクリーム色の面 + 黄色の塊 + 星、見出しは星 + 金の線 |
| 差分 | 追加ライム / 削除橙赤 | 追加金 / 削除赤 |
| Pets | 状態の小さなプレート(STATUS) | 白い吹き出し(しっぽ付き) |

## 動き(すべて一度きり。OS の設定と「装飾とエフェクト」でオフ)

| | フロンティア | アストラル |
|---|---|---|
| 時間 | 120 / 160 / 220ms | 180 / 240 / 280ms |
| イージング | cubic-bezier(0.2, 0, 0, 1)(直線的、跳ねない) | cubic-bezier(0.16, 1, 0.3, 1)(柔らかく減速) |
| メッセージ | 不透明度 + 横 8px | 不透明度 + 上 8px + 0.985→1 |
| ポップアップ | 不透明度 + 上から 6px、上端の黄色の線が伸びる | 不透明度 + 0.94→1 |
| 押下 | 0.97 | 0.96 |
| 通知 | 0 → 1.2 → 1 で一度だけ現れる | 同じ |

公式サイトと動画はサンドボックスから開けなかったため、動きの値は記事の記述と推測による(実測ではない)。
