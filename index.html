LLM（大規模言語モデル）とは？

LLM = Large Language Model（大規模言語モデル）。日本語をはじめとする複数の自然言語を理解・生成できる AI 技術です。

定義

LLM は「Large Language Model」の略称で、膨大なテキストデータからパターンを学習し、新しいプロンプトに対して文章や回答を生成する深層学習モデル（Transformer 系アーキテクチャが主流）です。日本語でも自然に話せたり、翻訳や要約ができるようになります。

どうやって動くの？

大まかに言うと、以下のステップを繰り返しています：

  • 学習 — Internet 上の膨大なテキストを読み込み、言葉のつながりや文法、知識を学びます。
  • 推論 — ユーザーが入力したプロンプトを受け取り、次に続く文字列（トークン）を確率的に最もらしい順に並べ、テキストとして出力します。

よくある使い道

  • 会話・チャット — 質問に答えたり、アイデア出しをしたりします。
  • 翻訳 — 日本語と英語など言語間の変換。

  • 要約 — 長い記事やレポートを短くまとめます。

注意点

LLM は「知っている」わけではなく、学習したデータに基づいて確からしい（もっともらしい）出力をしているにすぎません。事実と異なる情報を生成する「ハルシネーション」や、偏った回答が出る可能性もあるため、人間が必ず確認することが重要です。
